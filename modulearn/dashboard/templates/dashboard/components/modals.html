LMS Launch Setup

Use the section that matches your LMS and LTI version.

LTI 1.3 is preferred for new Moodle and Canvas installs. LTI 1.1 remains available for legacy Canvas or Moodle tools that still rely on consumer key and shared secret launches.

Canvas Developer Keys / External Apps
LTI 1.3 Canvas Developer Key Recommended

In Canvas, create an LTI Developer Key. Manual entry requires the title, description, target link URL, OpenID Connect initiation URL, and a public JWK URL.

Supports Deep Linking: leave off for now. Use a regular assignment/course navigation placement that launches the Target link URI.

LTI 1.1 Canvas External App Legacy

Use the cartridge XML URL when Canvas asks for configuration by URL, or enter the launch URL, consumer key, and shared secret manually.

Moodle External Tool
LTI 1.3 Moodle LTI Advantage tool Recommended

In Moodle, configure a tool manually, choose LTI 1.3, set Public key type to Keyset URL, then paste the fields below.

Default launch container: Embed, without blocks. Supports Deep Linking: leave off for now.

LTI 1.1 Moodle legacy external tool Legacy

Moodle can add a legacy tool from the cartridge URL, or you can manually enter the launch URL, consumer key, shared secret, and custom parameters.

Platform registration Store the LMS values ModuLearn needs to verify LTI 1.3 launches After the LMS admin creates the tool, paste the platform details here.
Moodle values

In Moodle, go to Plugins > Activity modules > External tool > Manage tools, open the tool card, and use View configuration details.

Copy Platform ID, Client ID, Deployment ID, Authentication request URL, Access token URL, and Public keyset URL into the form.

Canvas values

In Canvas, create or open the LTI Developer Key, copy its Client ID, then install the tool in the account or course.

Use the Canvas issuer and endpoints from your Canvas configuration. The defaults button fills the common Canvas paths from the issuer/base URL.

Other LMS values

Paste the exact issuer, client ID, deployment ID, OIDC authorization endpoint, OAuth token endpoint, and JWKS URL supplied by the LMS platform.
